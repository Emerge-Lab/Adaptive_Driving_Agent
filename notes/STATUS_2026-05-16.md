## What's implemented

**GOAL_TRIAL (goal_behavior=3)** — adaptive ego policy with in-context adaptation across `k` trials per episode. The mechanism is end-to-end wired and mechanism-validated (3-agent audit, trial timing exact, KV cache bit-identical across trial boundary).

Hard invariants (do NOT break):
- Env owns the trial clock; ego goes off-map (`removed=1`) on goal reach
- KV cache slots for `removed=1` egos **freeze** (no overwrite) — `pufferl.py` cache writeback gating
- `removed` is shared across multiprocessing workers via SHM (`vector.py` RawArray)
- Training attention masks removed slots via `limbo_bias`; **diagonal stays open** (`models.py`) to prevent NaN on all-limbo rows
- PPO loss is gated by `valid_mask = ~removed` (`pufferl.py`) — pg/v/entropy weighted to alive ego-only timesteps
- GAE `bootstrap_stop = terminals | truncations | removed` — value bootstrapping stops at goal-reach
- Per-trial clean-success score: `log.score += 1/max_trials` if `current_goal_reached && !collided_this_trial`

Reward weights (adaptive ego): `γ=0.995`, `collision_lb=-2`, `offroad_lb=-2`, `lane_reward=0.025`, `discount_lb/ub=0.4/1`, `entropy_ub` varies by partner.
